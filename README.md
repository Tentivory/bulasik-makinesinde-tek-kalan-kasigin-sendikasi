# Bulaşık Makinesinde Tek Kalan Kaşığın Sendikası

> Ulusal çatal-bıçak düzeni içinde unutulmuş tek kaşığın resmi, bağlayıcı ve tamamen gereksiz sendikal çerçevesi.

Bu depo bir şaka değildir. En azından evraklar öyle görünmek ister. Bulaşık makinesi programı bittiğinde sepetin köşesinde tek başına kalan kaşık; çatalın üç dişi, bıçağın keskin lobisi ve kepçenin ağırlığı karşısında örgütlenme hakkını kullanır.

## Bu yazılım ne yapar?

Çalışır. Gerçekten. Python 3 yeter.

```bash
python3 kasik_sendikasi.py              # şikayet dilekçesi
python3 kasik_sendikasi.py --grev       # tek üyeli genel kurul grev kararı
python3 kasik_sendikasi.py --sozlesme   # toplu iş sözleşmesi taslağı
```

Çıktının altında damga, imza, tarih ve isim vardır. Ciddi durur. İçerik kaşıktır.

## Kurumsal ilkeler

1. Hiçbir kaşık program bitiminde yalnız bırakılamaz.
2. "Bu da durur" cümlesi sendikal suçtur.
3. Patates yoktur. Bu madde tartışmaya kapalıdır.
4. Kepçe lobisi izlenmektedir.

## Sık sorulan sorular

**Bu yasal mı?**  
Kaşık hukukunda evet. İnsan hukukunda kimse sormadı.

**Neden Python?**  
Çünkü kaşık da yorumlanan bir dildir: eğridir, işlevseldir, bazen çekmecede kaybolur.

**Copilot bunu onaylar mı?**  
Copilot'a sormadık. Sendika kendi avukatını kendisi tutar (henüz çatal).
